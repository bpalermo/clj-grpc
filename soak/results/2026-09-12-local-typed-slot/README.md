# The typed-slot read path on the soak — protoc-gen-clojure 0.7.0 (f3a8449), local x86, 2026-09-12

Plan item 5's system number. One-variable pair: `main.jar` = clj-grpc main
(clj-protobuf 0.3.0, the committed fixture, `codec/get-field` reads) vs
`slot.jar` = the same tree with the compiled fixture regenerated by the
released 0.7.0 (`rt/compiled-message?` → `rt/slot` by declaration index,
codec fallback). Same pinned harness (server cores 2–5, driver 6–9,
loopback), chart defaults on both (`-Xmn256m`, `INBOUND_CREDITS=8`),
streaming, 40 streams, realistic tier (1 KB), 4 server cores. CPU per
message below is the arm's cgroup counter delta over messages received,
from the logs at full precision (`harness/cpu5.py`); the collector's
3-decimal `tables.md` rounds these away.

**Read only the clean rows.** `PREDICTION.md` records three perturbations:
a peer benchmark on the other cores of the socket (shared L3 — pinning is
not isolation), a native-image build from the clj-grpc workspace, and one
collector run of my own. The rows read are the first-pass `:direct` pairs
(host quiet from ~11:50), the `*2` replicate pairs, and the `*3` past-the-
knee pair; unpinned-core load stayed under ~65% through all of them.

| shape | main → typed-slot, µs/msg | Δ CPU/msg | capacity |
|---|---|---|---|
| `:direct`, one connection | 7.8 → 7.1 | **−6 to −9%** | ~129k → ~139k, **+8%** |
| virtual threads, one connection | 9.6 → 9.0 | **−4 to −6%** | ~388k → ~397k (+2%, within the floor); p50 at the top step 1.9 → 0.6 ms |
| `:direct`, eight connections | 9.8 → 9.8 below the knee; 8.0 → 7.8 past it | −0.3 to −3% | ~470k → ~480k (+2%) |
| virtual threads, eight connections, two loops | 10.1 → 10.1 | nil (−0.2 to −1.2%) | 376k → 375k |

Reading: the typed read path saves a roughly constant ~0.5–0.7 µs per
message, so it is worth 4–9% where the message is cheapest (one connection,
where the loop carries everything) and 0–3% on the eight-connection shapes
whose per-message cost is dominated by the loops' I/O. clj-protobuf's
prediction (−5–10% at 1 KB) held on the single-connection shapes and the
eight-connection ones came in under it. Correctness stood throughout:
0.7.0's emission passes clj-protobuf's full behavioural suite and
clj-grpc's suite on the regenerated fixture. The implicit-presence
substitution path is covered by clj-protobuf's equivalence test and by no
bench number, this one included (the soak's protos have explicit presence
everywhere).
